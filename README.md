# Amnezia WG-Easy — форк с DPI-обходом

Форк [amnezia-wg-easy](https://github.com/amnezia-vpn/amnezia-wg-easy) с доработками под работу в условиях блокировок.

## В чём была проблема оригинала

- Нет полной поддержки DPI-обхода (S3, S4, I1 для AmneziaWG) — конфиги клиентов могли не подходить для обхода блокировок.
- QR по умолчанию — полный конфиг с I1 не помещается в QR; в форке QR возвращён в виде компактного конфига (без I1), полный конфиг — через «Скачать» / «Просмотр».
- Деплой требовал вручную прописывать IP, пароль и т.п.

## Что изменено в этом форке

- **DPI/QUIC** — клиентские конфиги содержат S3, S4, I1; конфигурация совместима с AmneziaWG для обхода DPI.
- **UI** — кнопка «QR» открывает QR с компактным конфигом (без I1; через QR менее устойчив к DPI, для полного обхода — «Скачать»); «Просмотр» и «Скачать» — полный конфиг с I1. Уведомление об обновлении отключено по умолчанию.
- **Деплой** — скрипт `./deploy.sh` сам подставляет внешний IP и генерирует пароль при первом запуске.
- **Docker** — всё через `docker compose`, volume для данных `/etc/amnezia/amneziawg`.

## Быстрый запуск

```bash
git clone https://github.com/netort/amnezia-wg-easy.git
cd amnezia-wg-easy
./deploy.sh
```

Скрипт создаст `.env` (если его нет), попытается определить внешний IP и сгенерировать пароль, затем поднимет контейнер. Web UI и пароль выводятся в конце.

## Ручная настройка

Файл `.env` создаётся из `.env.example`. Если нужно задать свой `WG_HOST` или `PASSWORD` — отредактируйте `.env` до запуска или после, затем перезапустите: `docker compose up -d`.

## Требования

- Docker и Docker Compose
- Linux-хост с поддержкой WireGuard в ядре
