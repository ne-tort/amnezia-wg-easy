# Отличия от amnezia-wg-easy

Кратко: что изменено в форке относительно оригинального [amnezia-wg-easy](https://github.com/amnezia-vpn/amnezia-wg-easy), зачем и чем это лучше.

| Что изменено | Зачем | Чем лучше |
|--------------|--------|-----------|
| **Профили маскировки** (QUIC, DNS, SIP, STUN, WebRTC, DTLS) | В оригинале по сути один I1 (QUIC). Разная цензура и DPI по протоколам. | Выбор протокола под ситуацию; короткие подписи (DNS, STUN, WebRTC, DTLS) дают читаемый QR и меньше зависимость от одного fingerprint. |
| **Уровни I0–I5 в UI** | Явный выбор уровня обфускации. | I0 — без подписи (совместимость/минимальный трафик); I1–I5 — цепочка по рекомендациям Amnezia; понятно пользователю. |
| **Кнопка профиля скрыта при I0** | При I0 подпись не используется. | Нет лишнего выбора протокола, когда он не влияет. |
| **QR только для «коротких» профилей** | Полный конфиг с длинным I1 (QUIC/SIP) в QR плохо читается. | Кнопка QR показывается только там, где конфиг реально помещается и сканируется; для QUIC/SIP — только «Скачать». |
| **Компактный QR по умолчанию выключен** | Раньше QR по умолчанию без I1. | По умолчанию конфиг с I1; компактный режим при необходимости включается через `WG_QR_COMPACT=true`. |
| **Порядок кнопок: сначала I, потом профиль** | Логика «сначала уровень, потом протокол». | Соответствует порядку принятия решений. |
| **Деплой: deploy.sh, авто IP и пароль** | Упростить первый запуск. | Меньше ручных шагов; один скрипт. |
| **Один JSON (wg0.json) вместо БД** | Минимализм, один админ. | Проще бэкап, нет миграций; для сценария «одна панель» достаточно. |

От общего **wg-easy** (Nuxt, БД, мультипользователи) мы сознательно отличаемся: один конфиг, один пароль, фокус на AmneziaWG и DPI; без БД, мультипользовательности и 2FA. Архитектура минимальная под self-hosted сценарий.

**Сравнение с исходным wg-easy** (что добавлено по слоям, архитектура, модель использования) — [wg-easy-vs-our-project.md](wg-easy-vs-our-project.md). **Особенности проекта и отставание от wg-easy** (назначение, технические пробелы: IPv6, CIDR, метрики) — [PROJECT-FEATURES-AND-WG-EASY-GAP.md](PROJECT-FEATURES-AND-WG-EASY-GAP.md).

**Ссылки:** [AmneziaWG | Amnezia Docs](https://docs.amnezia.org/documentation/amnezia-wg). Свой I1 можно получить из Wireshark (фильтр по протоколу → Copy as Hex Stream → `I1=<b 0x...>`) или задать через env: `I1_QUIC`, `I1_DNS`, `I1_SIP`, `I1_STUN`, `I1_WEBRTC`, `I1_DTLS`. Официальная инструкция: [How to extract a protocol signature](https://docs.amnezia.org/documentation/instructions/new-amneziawg-selfhosted/#how-to-extract-a-protocol-signature-for-amneziawg-manually).
