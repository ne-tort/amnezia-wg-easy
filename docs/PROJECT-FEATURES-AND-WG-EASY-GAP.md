# Ключевые особенности проекта и отставание от wg-easy

Тезисная сводка: назначение и смысл нашего проекта, его сильные стороны и проблема отставания от актуального wg-easy (оригинал на обычном WireGuard). Акцент на технических отличиях; административные фичи — кратко.

---

## Назначение и смысл проекта

Веб-админка для self-hosted AmneziaWG: один сервер, один администратор, минимум зависимостей. Цель — обход блокировок (DPI) при простом деплое и управлении. Не «панель как сервис» и не мультитенантная платформа, а инструмент для себя или команды: поднять сервер, выдать конфиги, при необходимости менять протокол маскировки и уровень обфускации под конкретную цензуру.

Основа — форк amnezia-wg-easy. Поверх добавлены: профили маскировки (QUIC, DNS, SIP, STUN, WebRTC, DTLS), уровни I0–I5 в UI, умная логика QR (только для коротких подписей), компактный QR по умолчанию выключен, скрипт deploy.sh с авто подстановкой IP и пароля, единое хранилище — один JSON (wg0.json).

---

## Ключевые особенности нашего проекта

- **AmneziaWG вместо обычного WireGuard:** демон и утилиты из образа amneziavpn/amneziawg-go; в конфиге — S3, S4, I1–I5, H1–H4, junk (Jc, Jmin, Jmax). Трафик маскируется под выбранный протокол; без этого обход DPI невозможен.
- **Профили маскировки:** QUIC, DNS, SIP, STUN, WebRTC, DTLS; выбор под тип цензуры; короткие подписи (DNS, STUN, WebRTC, DTLS) дают читаемый QR.
- **Уровни I0–I5 в UI:** явный выбор обфускации; I0 — без подписи; при I0 кнопка выбора профиля скрыта; порядок кнопок — сначала I, потом профиль.
- **QR:** кнопка показывается только для профилей с короткой подписью; для QUIC/SIP — только «Скачать». Компактный режим (без I1) по умолчанию выключен.
- **Один конфиг (wg0.json), один пароль:** нет БД, миграций; бэкап — копия файла. Деплой через deploy.sh с авто IP и паролем.
- **Целевой сценарий:** блокировки, один владелец панели, без мультитенантности и монетизации.

---

## Проблема отставания от wg-easy

Кодовая база восходит к старой ветке wg-easy. **Актуальный wg-easy** ([wg-easy/wg-easy](https://github.com/wg-easy/wg-easy)) — проект на обычном WireGuard, не Amnezia — ушёл вперёд на сотни коммитов (порядка 400). Там другой стек (Nuxt, БД), множество фич и улучшений интерфейса, сети и мониторинга. Мы не мержим их напрямую: другой протокол (AmneziaWG), другой фокус (DPI, минимализм, один админ). Итог: по **функциональности панели** (подсети, IPv6, метрики, UX) мы отстаём; по **обходу блокировок** — впереди за счёт AmneziaWG и профилей маскировки.

---

## Что есть в wg-easy и нет у нас — технические аспекты

- **IPv6:** в wg-easy — dual-stack, отдельные IPv4/IPv6 подсети в UI, выдача IPv6-адресов клиентам, переменная DISABLE_IPV6. У нас — только `::/0` в AllowedIPs по умолчанию; выдачи IPv6-адресов и настроек dual-stack нет.
- **Подсети и CIDR:** в wg-easy — смена CIDR через UI (IPv4 и IPv6), поддержка routed setup. У нас — одна подсеть 10.8.0.0/24, адрес клиента — один IPv4.
- **Метрики:** в wg-easy — endpoint Prometheus (`/metrics/prometheus`), интеграция с Grafana. У нас — нет.
- **Хуки:** в wg-easy — PreUp/PostUp/PreDown/PostDown настраиваются (в т.ч. через UI/БД для интерфейса). У нас — только из env для сервера, без UI.
- **QR:** в wg-easy — перебор уровней коррекции ошибок при переполнении. У нас — фиксированный уровень; для длинных профилей кнопка QR скрыта.
- **Валидация и API:** в wg-easy — схемы (Zod), единый формат ошибок, расширенный API. У нас — минимальная валидация.

Приоритет нашего проекта — обход DPI и простота (один конфиг, один пароль); перечисленные технические фичи сознательно или из-за истории не переносились.

---

## Что есть в wg-easy и нет у нас — административное

Мультипользователи, роли, 2FA (TOTP), one-time links, срок действия клиента (expiration); в обсуждениях — OIDC. У нас — один пароль, один список клиентов; мультиаккаунтинг в текущей модели не планируется.

---

## Итог

Проект силён обходом DPI (AmneziaWG, профили, уровни I0–I5) и минимализмом (один JSON, deploy.sh). Отстаёт от wg-easy по технической оснащённости панели (IPv6, CIDR, метрики, хуки через UI) и по административным возможностям (мультипользователи, 2FA, one-time links, expiration). Это следствие разной цели: wg-easy — универсальная панель для WireGuard с развитым функционалом; наш форк — узко заточен под обход блокировок при минимальной сложности.
